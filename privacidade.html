Política de Privacidade

Esta política explica de forma clara como tratamos dados pessoais quando interages com o website e com os nossos canais de contacto.

1. Quem trata os teus dados

A Cobrait é a entidade responsável pelo tratamento dos dados pessoais recolhidos através deste website e dos formulários de contacto associados.

2. Dados recolhidos

  • Dados de identificação e contacto: nome, email, telefone e empresa.
  • Dados de contexto comercial: mensagem, objetivo do projeto e informação enviada voluntariamente.
  • Dados técnicos: endereço IP, browser, dispositivo, páginas visitadas e eventos de navegação.

3. Finalidades e base legal

Tratamos os dados para responder a pedidos, preparar propostas, melhorar o desempenho do site e cumprir obrigações legais.

Bases legais aplicadas: consentimento, diligências pré-contratuais, execução contratual e interesse legítimo.

4. Partilha e transferências

Os dados podem ser partilhados apenas com fornecedores necessários para operação técnica (hosting, analytics, ferramentas de comunicação), sob obrigações de confidencialidade e segurança.

Não vendemos dados pessoais a terceiros.

5. Conservação

Conservamos os dados apenas pelo período necessário para as finalidades descritas, ou pelo prazo legal aplicável quando exigido por lei.

6. Direitos do titular

Podes pedir acesso, retificação, apagamento, limitação, oposição e portabilidade dos teus dados.

Acesso Retificação Apagamento Portabilidade

7. Segurança e contacto

Aplicamos medidas técnicas e organizativas adequadas para proteger os dados pessoais.

Para pedidos relacionados com privacidade, contacta: cobrait@geral.pt.
