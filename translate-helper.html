🌍 Cobrait Translation Helper

Como usar:

  1. Clica em "Extrair Textos" para ver todos os textos que precisam tradução
  2. Clica em "Traduzir com Google" para traduzir automaticamente
  3. Copia o output e cola num ficheiro .txt
  4. Usa esse output para adicionar os atributos data-fr, data-de, etc. aos ficheiros HTML
